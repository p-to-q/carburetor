# code of conduct

carburetor follows version 2.1 of the
[Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
this page summarizes the parts most relevant to an early-stage research,
hardware, and software project.

## the short version

- be direct, stay kind. technical disagreement is welcome; personal attacks are
  not.
- assume good faith. most issues come from missing context, not bad intent.
- credit work honestly. attribute ideas, measurements, photos, code, and bench
  data to their sources.
- keep the bar research-honest. if a number is projected, say so. if a feature
  is a stub, label it.
- respect safety. fuel, heat, exhaust, and spinning parts are not aesthetic
  flourishes.
- no harassment, in any channel.

## scope

this applies to every space the project owns: the GitHub repo, issues, pull
requests, linked chat channels, demo venues, print-production coordination, and
one-on-one communication about the project.

## reporting

1. open a private security advisory if the incident also involves a security or
   safety concern.
2. otherwise, contact the project maintainer through the channel listed on the
   GitHub organization or repository.
3. we aim to acknowledge within 5 business days.

retaliation against a reporter is itself a violation.

## enforcement

first incidents get a private, specific note. repeated or severe incidents can
lead to a temporary or permanent ban from project spaces. decisions are made by
the project maintainers and can be appealed in writing.

## full text
