# TASTE

inherited from p-to-q's `wittgenstein/TASTE` and adjusted for this project.

a project-specific taste section. read it before opening a PR; if your change disagrees, push back with a `docs/rfcs/`.

## about engineering

- flat is better than nested.
- printability is a great feature.
- human-readable interfaces for machine-produced things.
- overly abstract means narcissism.
- programming is a way of thinking, not a rote skill.
- long variable names don't hurt anyone. **units written into the variable name** are non-negotiable. `volume_mL`, not `volume`.
- a receipt is worth a thousand claims. measure first.
- five layers, not three or seven. naming is doing.

## about physical making

- weld marks visible. brass patinates. fuel stains.
- every part has a name and a callout.
- the case is canvas, not aluminum, and the canvas is olive, not black.
- the warm-up is a feature. the wait is the point.
- a tool whose hazards are visible is safer than a tool whose hazards are hidden.
- repairable means: someone in 2050 can still fix this.

## about communication

- lowercase-leaning. short paragraphs. declarative.
- no emoji in prose. emoji only as taxonomic status markers (🧪 ⚠️ ✅ 🔴).
- no exclamation marks. no "let's." no "literally" (unless meaning is literal mechanical). no "just" softeners.
- adjectives earned, not decorative.
- write to three readers at once: an engineer, a researcher, a user.
- a manifesto is not a sermon. the user writes the prose. agents leave scaffolds.

## about software

- two surfaces, one architecture: typescript primary, python prototype.
- typed contracts at every boundary.
- golden fixtures pinned by sha-256.
- manifest spine on every run.
- the receipts table is CI-gated.
- a binary frame format beats JSON for reproducibility. always.

## about identity

- the project is for understanding power. it is not for proving smartness.
- the project respects users. it does not patronize them.
- the project respects fuel. it does not romanticize fuel.
- the project is not a meme. it is a working device that happens to be unusual.
- AI should serve as deeper connective tissue that strengthens humans.
- to sincerely elevate the species.

`Q.E.D.`
