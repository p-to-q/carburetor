# deferred edizione production files

these files describe the print production pipeline for edizione I: vendor RFQs, pricing models, distribution plans, pre-press checklists, and promotional copy.

they are deferred — not deleted — because the edizione's content depends on bench data, golden fixtures, and measured receipts that do not yet exist. the production pipeline becomes relevant when:

1. the simulator produces real golden fixtures with measured numbers.
2. the receipts table in README carries ✅ instead of ⚠️.
3. at least one physical unit has been built and a postmortem filed.

until then, the vision documents (spec.md, spine.md, typography.md, colophon.md) remain in the parent directory as structural authority.

moved here on 2026-05-20 during the v0.1 surface audit.
