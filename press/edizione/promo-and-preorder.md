## social outreach plan

minimal. the project is not a marketing exercise.

### channels

- **carburetor.wtf** — primary. pre-order banner on the landing page once page goes live.
- **github.com/p-to-q/carburetor** — README adds a small "edizione I available" notice with a link.
- **personal accounts** (user's twitter / mastodon / cohost / wherever) — one post on launch, one post mid-run.
- **the gift list itself** — the 25 gifted recipients will share organically. that is the channel.

### no

- no paid ads.
- no influencer outreach.
- no email blast to anyone we don't already correspond with.
- no countdown timers.
- no "limited time offer" language.

### the announcement post


## the print-on-demand option (after edizione I sells out)

once the 100-unit run is gone, switch the pre-order page to a "POD edition" via Lulu:

- coated cover only (brass via foil stamp at +$1.50/unit)
- ~$30 retail (covers POD overhead + Lulu's cut)
- ships globally
- no numbering, no hand-stamp
- not the same object — explicitly labeled "POD edition"

the POD edition exists so that "I missed the first 100" does not have to be a permanent exclusion. it is the inferior version on purpose. that is OK.

`Q.E.D.`
